NOTE 01

병서와 연서

병서는 자음 글자를 나란히 적고, 연서는 이어 적는다. 병서는 기본자가 아니다. 병서는 현대 국어에서도 쓰인다. 합용병서·각자병서의 세부 구분은 수업 교과서 범위 밖이다.

NOTE 02

모음 기본자

ㆍ는 하늘, ㅡ는 땅, ㅣ는 사람을 본떴다. 모음 기본자도 상형의 원리로 만들었지만 발음 기관을 본뜬 것은 아니다. 발음 기관을 본뜬 것은 자음 기본자다.

NOTE 03

초출자와 재출자

초출자는 기본자를 결합해 만든 모음자이고 재출자는 초출자에 획을 더하여 만든 모음자다. 수업에서는 초출자를 단모음, 재출자를 이중모음으로 정리했다. 합용으로 만들어진 글자가 모두 이중모음인 것은 아니다.

NOTE 04

합성과 합용

합성은 기본자 및 초출자 등을 결합해 모음자를 만드는 제자 원리다. 합용은 여러 모음을 합하여 적는 원리다. 교과서 83쪽 활동을 모두 합용이라고 볼 수 없는 이유는 아래아(ㆍ)가 포함되어 있기 때문이다. 실제 카드 그림은 교과서 확인이 필요하다.

NOTE 05

모아쓰기와 풀어쓰기

한글은 초성·중성·종성을 음절 단위로 모아 쓴다. 음절에는 모음이 반드시 필요하므로 초성과 종성만으로 음절이 성립하지 않는다. 모아쓰기는 음절 경계를 알아보기 쉽다.

NOTE 06

한글의 가치

과학성은 체계적인 제자 원리, 독창성은 독자적인 창제 원리, 실용성은 배우고 쓰기 편리함을 뜻한다. 선생님은 설명과 가치 연결형 문제를 예고했다.

NOTE 07

한글과 한국어

한글은 문자이고 한국어는 언어다. 한글의 우수성을 알리는 행사에서 우리말 퀴즈 대회나 순우리말 수필 쓰기는 한국어 어휘와 표현을 다루므로 취지에 맞지 않을 수 있다. 교과서 88쪽 출제 포인트다.

NOTE 08

음운의 정의

음운은 말의 뜻을 구별해 주는 소리의 가장 작은 단위다. ㄸ은 하나의 음운이다. 말소리의 길이도 음운적 요소지만 개별 단어의 장단을 직접 구별하는 문제는 내지 않겠다고 했다.

NOTE 09

최소 대립쌍

한 음운만 달라 뜻이 달라지는 두 말이다. 곰/몸은 ㄱ과 ㅁ 한 음운 차이로 성립한다. 달/딸은 ㄷ과 ㄸ 한 음운 차이로 성립한다. 곰/밤은 첫 자음과 모음 두 음운이 달라 성립하지 않는다. 알/아들도 성립하지 않는다.

NOTE 10

자음: 발음 위치

양순음 ㅂㅃㅍㅁ / 치조음 ㄷㄸㅌㅅㅆㄴㄹ / 경구개음 ㅈㅉㅊ / 연구개음 ㄱㄲㅋㅇ / 후음 ㅎ. ㄹ과 ㅅ은 치조음, ㅈ은 경구개음이다.

NOTE 11

자음: 발음 방법과 울림

파열음 ㄱㄲㅋ ㄷㄸㅌ ㅂㅃㅍ / 파찰음 ㅈㅉㅊ / 마찰음 ㅅㅆㅎ / 비음 ㅁㄴㅇ / 유음 ㄹ. 울림소리인 자음은 ㅁㄴㅇㄹ이며 모든 모음도 울림소리다.

NOTE 12

모음: 분류 기준

단모음과 이중모음을 구별한다. 단모음은 혀의 최고점 앞뒤 위치에 따라 전설/후설, 혀의 높이에 따라 고/중/저, 입술 모양에 따라 원순/평순으로 구분한다.

NOTE 13

단모음 체계표

고모음: 전설 평순 ㅣ, 전설 원순 ㅟ, 후설 평순 ㅡ, 후설 원순 ㅜ. 중모음: 전설 평순 ㅔ, 전설 원순 ㅚ, 후설 평순 ㅓ, 후설 원순 ㅗ. 저모음: 전설 평순 ㅐ, 후설 평순 ㅏ. 이 표는 일반 학교 문법을 참고해 보충한 것이며 녹음에서 전부 낭독된 것은 아니다.

NOTE 14

선생님 예상 문제

병서 현대 사용 여부, 기본자 여부, 모음 기본자의 상형 원리, 합성·합용 구분, 83쪽 아래아 서술형, 모아쓰기의 필수 모음, 한글의 세 가치 연결, 88쪽 행사 목적, 음운 정의, 최소 대립쌍 서술형, 울림소리인 자음, 자음 조음 위치, 모음 세 분류 기준.
